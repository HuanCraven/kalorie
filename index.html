1 · Vyfoť jídlo

Vyfoť talíř shora nebo pod úhlem 45°. Napiš, co na fotce nejde poznat — velikost, čím je to plněné, kolik oleje. Odhad se tím zpřesní víc než čímkoli jiným.

Způsob odesílání
Jak na to

Sdílení z Androidu vždycky otevře nový chat mimo projekt, kde instrukce neplatí. Použij proto tenhle postup — zpráva pak není potřeba vůbec:

  1. Ulož fotku do telefonu (tlačítko níž)
  2. Otevři Claude → svůj projekt → nový chat
  3. Přilož fotku z galerie a odešli — bez psaní

Bez projektu se musí ke každé fotce poslat i zadání. Zaškrtnutím výše se postup zjednoduší.

2 · Pošli to Claudeovi

⚠ Důležité ke sdílení

Android u sdílení často zahodí přiložený text a pošle jen fotku. Zadání se proto vždycky kopíruje i do schránky — v Claude ho dlouhým stiskem vlož do zprávy k fotce, teprve pak odešli. Bez zadání odpoví větou místo dat.

Alkohol

Aplikace pak počítá, kolik ti do limitu ještě zbývá, a řekne ti to v pivech. Orientačně: 10 g/den ≈ pivo 12° obden. Změna se uloží sama.

Claude API — odhad z fotky bez kopírování

S vlastním API klíčem pošle aplikace fotku Claudovi přímo a rozpis se vyplní sám. Klíč zůstává jen v tomhle telefonu a není součástí zálohy. Bez klíče funguje původní postup přes chat.

Synchronizace mezi zařízeními

Data se slučují přes jediný soubor v tvém privátním repozitáři na GitHubu. Nikam jinam neodcházejí. Na obou zařízeních zadej stejný repozitář a token — pak už se všechno srovnává samo.

Šifrování

Heslo zadáš na každém zařízení jednou. Data se pak do repozitáře ukládají zašifrovaná — bez hesla je nikdo nepřečte, ani kdyby se k souboru dostal. Heslo si zapiš, nikde jinde než v těchhle zařízeních není a nedá se obnovit.

Párování telefonu

Aby ses nemusel na telefonu trápit s opisováním tokenu: na počítači si nech zobrazit kód a telefonem ho naskenuj. Kód obsahuje token — nefoť ho a nenech si ho přes rameno přečíst.

Jak si to jednou nastavit
  1. Na GitHubu založ privátní repozitář, třeba kalorie-data. Prázdný stačí.
  2. Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Expiration klidně No expiration.
  3. Repository access → Only select repositories → vyber ten nový repozitář.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Vygenerovaný token vlož sem. Totéž zopakuj na druhém zařízení.
